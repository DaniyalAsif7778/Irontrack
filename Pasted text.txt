# IronTrack — UI Structure Reference

> Detailed breakdown of the **Workout page cards**, **Routine prayer cards (with timer)**, and **Home page** structure.
> Each section lists the component file, layout, every visual element, the Tailwind classes used, and the governing code.

## 1. Workout Page

**File:** `src/pages/Workout.jsx`

The Workout page is a two-screen flow: **Plan** → **Mode**. A single `screen` state toggles between them.

### Page Shell

```jsx
<div className="fixed inset-0 bg-background flex flex-col lg:pl-64">
  <div className="max-w-2xl lg:max-w-4xl mx-auto w-full flex flex-col flex-1 min-h-0">
    {screen !== "mode" && <div className="pt-12 shrink-0" />}
    <div className="flex-1 overflow-y-auto px-5 pb-24 lg:pb-10">
      {/* plan or mode screen */}
    </div>
  </div>
  <BottomNav />
</div>
```

| Element | Tailwind | Purpose |
|---|---|---|
| Root | `fixed inset-0 bg-background flex flex-col lg:pl-64` | Full-screen flex column; `lg:pl-64` leaves room for the desktop sidebar. |
| Container | `max-w-2xl lg:max-w-4xl mx-auto w-full flex flex-col flex-1 min-h-0` | Centers content, caps width on mobile/tablet, widens on desktop. |
| Top spacer | `pt-12 shrink-0` | Pushes content below the status-bar area on the plan screen. |
| Scroll area | `flex-1 overflow-y-auto px-5 pb-24 lg:pb-10` | Scrollable body; `pb-24` clears the mobile bottom nav. |

#### Countdown Ring (used by Rest + Rep timers)

A circular SVG progress ring with the seconds countdown in the center.

```jsx
function CountdownRing({ total, left, color, size = 128 }) {
  const r = 44;
  const circ = 2 * Math.PI * r;
  const pct = total > 0 ? ((total - left) / total) : 0;
  return (
    <div className="relative" style={{ width: size, height: size }}>
      <svg className="w-full h-full -rotate-90" viewBox="0 0 100 100">
        <circle cx="50" cy="50" r={r} fill="none" stroke="hsl(var(--secondary))" strokeWidth="7" />
        <circle cx="50" cy="50" r={r} fill="none" stroke={color} strokeWidth="7}
          strokeDasharray={circ} strokeDashoffset={circ - pct * circ} strokeLinecap="round"
          style={{ transition: "stroke-dashoffset 1s linear" }} />
      </svg>
      <div className="absolute inset-0 flex flex-col items-center justify-center">
        <span className="text-2xl font-black">{left}</span>
        <span className="text-[9px] text-muted-foreground uppercase tracking-wide">sec</span>
      </div>
    </div>
  );
}
```

- **Set Rest** ring color: `hsl(var(--primary))`
- **Exercise Rest** ring color: `hsl(var(--chart-3))`
- **Rep Timer** ring color cycles by phase: eccentric → `hsl(var(--primary))`, pause → `hsl(var(--chart-4))`, concentric → `hsl(var(--accent))`

| Element | Tailwind |

function StatusIcon({ status }) {

}

### 2D. The Routine Focus Timer (TaskTimer)

**File:** `src/components/routine/TaskTimer.jsx`

When a non-prayer task's play button is tapped, `startActiveTaskTimer()` saves the task to localStorage and a **floating timer widget** appears at the bottom-right of every page (it's mounted globally in `App.jsx`).

#### Timer Constants

```js
export const TIMER_WORK_SECS  = 45 * 60;  // 45-minute focus session
export const TIMER_BREAK_SECS = 15 * 60;  // 15-minute break
```

The timer is a **Pomodoro-style** work/break cycle: 45 min focus → 15 min break → repeats. It auto-transitions between phases and fires a browser notification at each switch.

#### Widget Shell

```jsx
<div className="fixed bottom-20 lg:bottom-6 right-3 lg:right-6 z-40 w-64 bg-card border border-border rounded-2xl shadow-2xl p-4 space-y-3">
```

| Element | Tailwind |
|---|---|
| Position | `fixed bottom-20 lg:bottom-6 right-3 lg:right-6 z-40` (sits above the mobile bottom nav) |
| Size | `w-64` |
| Surface | `bg-card border border-border rounded-2xl shadow-2xl p-4 space-y-3` |

#### Header — phase icon + label + close

```jsx
<div className="flex items-center justify-between">
  <div className="flex items-center gap-2 min-w-0">
    {phase === "work"
      ? <Brain className="w-4 h-4 text-blue-400 shrink-0" />
      : <Coffee className="w-4 h-4 text-green-400 shrink-0" />}
    <span className="text-xs font-semibold text-foreground truncate">
      {phase === "work" ? "Focus — 45 min" : "Break — 15 min"}
    </span>
  </div>
  <Button variant="ghost" size="icon" className="h-7 w-7 shrink-0" onClick={handleClose}>
    <X className="w-3.5 h-3.5" />
  </Button>
</div>
```

#### Task Name

```jsx
<p className="text-sm font-medium text-foreground truncate -mt-1">{taskTitle}</p>
```

#### Progress Ring + Countdown

A circular SVG ring (same technique as the workout countdown). The ring fills as time elapses; the center shows `mm:ss`.

```jsx
<div className="relative w-24 h-24">
  <svg className="w-full h-full -rotate-90" viewBox="0 0 100 100">
    <circle cx="50" cy="50" r="44" fill="none" stroke="hsl(var(--secondary))" strokeWidth="8" />
    <circle cx="50" cy="50" r="44" fill="none"
      stroke={phase === "work" ? "hsl(var(--primary))" : "hsl(var(--accent))"}
      strokeWidth="8"
      strokeDasharray={`${2 * Math.PI * 44}`}
      strokeDashoffset={`${2 * Math.PI * 44 * (1 - pct / 100)}`}
      strokeLinecap="round"
      style={{ transition: "stroke-dashoffset 0.5s ease" }} />
  </svg>
  <div className="absolute inset-0 flex items-center justify-center">
    <span className="text-xl font-bold font-mono tabular-nums text-foreground">{mins}:{secs}</span>
  </div>
</div>
```

- **Work phase** ring color: `hsl(var(--primary))` (blue)
- **Break phase** ring color: `hsl(var(--accent))` (green)

#### Controls

```jsx
<div className="flex gap-2">
  <Button variant={isRunning ? "secondary" : "default"} size="sm" className="w-24" onClick={() => setIsRunning(r => !r)}>
    {isRunning ? <><Pause className="w-3.5 h-3.5 mr-1.5" />Pause</> : <><Play className="w-3.5 h-3.5 mr-1.5" />Start</>}
  </Button>
  <Button variant="ghost" size="sm" onClick={handleReset}>
    <RotateCcw className="w-3.5 h-3.5" />
  </Button>
</div>
```

#### Persistence & Cross-Component Sync

- State is saved to localStorage on every tick (`saveActiveTaskTimer`), so it survives page reloads and navigation.
- It listens for `routine-timer-update` custom events and `storage` events, so if a task is started from the RoutineView, the widget reloads instantly.
- When the widget is closed (`handleClose`), it clears the stored timer and dispatches `routine-timer-update` so the RoutineView can update its active-task highlight.
